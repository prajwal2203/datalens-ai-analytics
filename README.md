# DataLens AI – Intelligent CSV Data Analyzer

DataLens AI is an interactive data analytics application that transforms raw CSV datasets into meaningful insights and visual reports.

## Features
- CSV dataset upload
- Automatic dataset profiling
- Missing-value and duplicate detection
- Statistical analysis
- Interactive data visualizations
- Correlation heatmaps
- Automated business insights
- Category-wise sales analysis
- Cleaned CSV export
- Statistical report download

## Tech Stack
- Python
- Streamlit
- Pandas
- NumPy
- Plotly

## Installation

```bash
git clone YOUR_REPOSITORY_URL
cd datalens-ai
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## Usage
1. Launch the application.
2. Upload a CSV dataset.
3. Explore statistical summaries and visualizations.
4. Review automated insights.
5. Download reports and cleaned datasets.
